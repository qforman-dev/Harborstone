# Harborstone — GitHub Pages

Upload these files directly to your repository root. `index.html` must sit beside `styles.css`, `app.js`, `favicon.png`, and `assets`. In GitHub Settings → Pages, choose Deploy from a branch, `main`, and `/(root)`. No build step is required.

The contact form is connected to Formspree. Submit a test inquiry after deployment and confirm delivery in your Formspree dashboard.
