# Harborstone — GitHub Pages

Upload these files directly to the repository root. `index.html` must sit beside `styles.css`, `app.js`, `favicon.png`, and the `assets` folder.

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. No build step is required.

To preview locally, run `python3 -m http.server 8000` in this folder and open http://localhost:8000.

The contact form is connected to Formspree. Submit a test inquiry after deployment and confirm delivery in your Formspree dashboard.
